CLIMB · 형식적 모델 확장

Point → Multi

단일변이(point) escape 모델을 다중변이(multi) 변이체로 형식적으로 일반화한다. 세 항은 변이 집합 위의 합으로, 진화적 시간 t는 point↔multi 손잡이로 바뀐다.

대상 단일변이 → 변이 집합 M(v) 불변 CLIB offset κ=1 새 자유도 진화적 시간 t

공통 골격

두 모델 모두 세 신호를 z-표준화 후 선형결합해 순위를 매긴다. CLIB은 계수 1의 offset으로 동결.

score(·) = b0·z(S₁) + b1·z(S₂) + κ·z(CLIB),   κ = 1
Point

단일변이 모델

대상: WT의 단일 치환  x = xwt ⊕ (i: awt→a)

S₁ · semantic
‖ e(x) − e(xwt) ‖₁
S₂ · grammar
log P( a │ xwt, mask i )
CLIB · accessibility
log P( ci → a, t = 0.01 )

단일-염기 regime (t→0): "한 번의 뉴클레오타이드 변화로 도달 가능한가"

Multi

다중변이 모델

대상: 변이 집합  M(v) = { (i, ai) : ai ≠ aiwt },  |M| = k

S₁ · semantic
‖ e(v) − e(xwt) ‖₁
S₂ · grammar
Σ(i,a)∈M log P( a │ xwt, mask i )
CLIB · accessibility
Σ(i,a)∈M log P( ci → a, t )

다중-치환 regime (t 자유·큰 값): "시간 t 안에 이 변이 조합에 도달 가능한가"

특수화 관계 다중변이 모델은 k = 1, t → 0에서 단일변이 모델로 정확히 환원된다. 즉 point는 multi의 특수 경우다. CLIB의 다중변이 인수분해 P(xwt ⟶M v ; t) = ∏(i,a)∈M P(ci→a, t)는 위치독립 가정(get_clib_table)에서 곧바로 나온다.

왜 t가 손잡이인가 — CTMC

CLIB은 코돈 치환의 연속시간 마르코프 모형이다. 전이행렬 P(t) = exp(t·Q)에서 작은 t는 단일-염기 변화만, 큰 t는 다중 치환 경로를 허용한다. 오래된 종(고다양성)의 escape는 여러 변이의 조합으로 일어나므로 큰 t가 맞다 — 그리고 이는 데이터로 확인된다.

P(t) = exp(t·Q)   ⟹   작은 t : 단일-염기  ·  큰 t : 다중 치환
실증 (Wu2020 flu HA 조합 fitness, 3,456 다중변이) 다중-CLIB(t)와 fitness의 Spearman 상관이 t와 함께 증가:

운용상 주의

  • 부호 있는 가중 필요: 다중변이 표현형에선 S₁가 지배적이고 CLIB과 부호가 반대일 수 있어(예: 조합 fitness에서 semantic −0.46, CLIB +0.33), 등가중 CAC는 상쇄된다 → b0·b1을 지도(부호 포함) 적합.
  • 위치독립 가정: S₂·CLIB의 합 분해는 위치 간 에피스타시스를 무시한다; 고차 조합에서 신호 희석 관측(향후 결합항 고려).
  • t 선택: 종/변이 차수에 맞춰 t를 스윕하거나 내부 CV로 선택(단일변이 SARS는 t≈0.01 고정으로 충분).
