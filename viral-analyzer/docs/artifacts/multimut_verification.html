CLIMB · point→multi 검증 상세

다중변이 모델을 어떻게 검증했나

단일변이(point)에서 다중변이(multi)로의 확장을 세 데이터셋으로 검증했다 — 메커니즘(t-손잡이), escape 예측, 그리고 시간교란을 통제한 항원거리. 각 단계의 ground truth·방법·결과·한계를 상세히.

대상 Influenza HA (다중변이) 백본 ESM2-650M 검증 데이터셋 3

0. 무엇을 검증하나 — 다중변이 스코어의 정의

변이 집합 M(v) = {(i, aᵢ)}에 대해 세 신호를 계산한다:

semantic = ‖ e(v) − e(x_wt) ‖₁   (다중변이 전장 서열 임베딩)
grammar = ΣM log P(aᵢ │ x_wt, mask i)
CLIB(t) = ΣM log P(cᵢ → aᵢ, t)   (t = point↔multi 손잡이)

검증 질문은 둘이다 — (A) 큰 t가 다중변이 regime에 맞나(메커니즘)? (B) 다중변이 신호가 실제 escape를 예측하나?

데이터셋 2 · escape 예측 (B)

H3N2 항원 클러스터 — 다중변이 escape

실제 escape ground truth
ground truth
두 균주가 다른 항원 클러스터인가(Smith-2004, 14개 HK68…SW13, 연도 기반)
구성
실제 H3N2 HA 균주 34,836 중 라벨 30,271 → 클러스터당 ~40 균형 subsample = 555 균주 (각 균주 = 자연 다중변이체)
방법
다중변이 semantic(임베딩 L1) → 클러스터 차이 예측 AUROC
결과: AUROC(semantic → 다른 클러스터) = 0.769 (단일변이 DMS escape 0.60~0.64 대비 크게↑). 클러스터 순서 gap↑ → semantic 단조 증가(6.4→14.4).
결정적 한계: 항원 클러스터는 시간순이라 신호 상당부가 시간적 발산과 얽힘(semantic~year 0.83). "항원성" 자체를 잰 건지 "시간이 지났음"을 잰 건지 불분명 → 데이터셋 3에서 통제.
데이터셋 3 · 시간교란 통제

결과: 원상관 0.788은 대부분 시간(semantic~year 0.83, antigenic~year 0.84). 하지만 연도를 통제해도 부분상관 +0.289, 그리고 같은 해 균주끼리(n=2,749)도 semantic이 항원거리 예측 +0.508. |Δyr|≤2 +0.575, ≤5 +0.520.
해소 시간 드리프트가 불가능한 조건(동일 연도)에서도 ρ≈0.5 → 다중변이 semantic의 항원 예측은 시간의 부산물이 아니라 실제 항원 신호. B11의 핵심 caveat가 통제됐다.

종합

  • 메커니즘: 큰 t가 다중변이 regime에 맞음(Wu2020).
