Working paper

CLIMB: A Mechanistic, Label-Free, and Multi-Mutation Extension of Protein-Language-Model Viral-Escape Prediction

Research program on branch research/climb-labelfree · reproducible from viral-analyzer/scripts/

score = b0·S₁(semantic) + b1·S₂(grammar) + κ·CLIB  ·  κ = 1

Abstract

Protein language models (PLMs) rank viral mutations for immune escape by combining a semantic signal (embedding change) and a grammaticality signal (mutant plausibility), following CSCS (Hie et al., 2021). We develop CLIMB, adding a mechanistic third term — CLIB, a nucleotide-accessibility prior from a continuous-time Markov codon model — and study three questions: how CLIB should be incorporated, whether the weights can be chosen and validated without an escape answer key, and whether the single-mutation formulation transfers across strains, models, and species.

We find: (1) freezing CLIB as a unit-coefficient offset removes a circular in-sample fit, matches the honest supervised model, and carries cross-strain generalization; (2) the two protein weights can be set label-free from phylogenetic fitness, recovering the supervised weights and matching them on held-out escape (validated by leave-one-variant-out and prospective temporal forecasting); (3) escape signal comes from domain adaptation, not model size, and CLIB is SARS-CoV-2-specific — near-random on Influenza HA and HIV Env even with real codons. This motivates a point → multi generalization in which each term sums over a mutation set and evolutionary time t becomes free; multi-mutation semantic change then predicts real antigenic-cluster escape in H3N2 at AUROC 0.77 where single-mutation DMS escape was near-chance. All headline claims were re-checked by independent adversarial verification.

1. Introduction

Emerging viral variants evade immunity through escape mutations. Ranking a protein's ~24,000 single-residue mutations so escape mutations sit near the top is classically done with the CSCS score: S1 semantic change (embedding distance = antigenic novelty) and S2 grammaticality (mutant log-probability = viability), ranked as rank(S1)+rank(S2). Building on the domain-adapted CoVFit line, we add a mechanistic third signal and ask whether the model can be made honest, label-free, and cross-domain:

score = b0·z(S₁) + b1·z(S₂) + κ·z(CLIB),   κ fixed = 1

Contributions: (1) the CLIB offset (§4.1); (2) label-free coefficients and DMS-free validation (§4.2); (3) cross-strain/model/species scope (§4.3–4.5); (4) a point→multi extension (§4.6).

2. The CLIMB model

2.1 Signals

For a single mutant x = x_wt ⊕ (i: a_wt→a): S1 = ‖e(x)−e(x_wt)‖₁ with e = mean-pooled ESM2 embedding; S2 = log P(a | x_wt, mask i), the masked-marginal log-probability.

2.2 CLIB — a codon-accessibility prior (the offset)

A substitution is easier to reach with fewer nucleotide changes. A 4×4 rate matrix Q is estimated from a virus-specific single-base-substitution spectrum; transition probabilities over evolutionary time t are P(t)=exp(t·Q); per mutation CLIB = log P(codon→a, t), standardized. Q comes from an independent, far larger dataset than the escape labels, so CLIB is a mechanistic prior. It enters as a statistical offset (coefficient fixed κ=1, not learned), so only b0, b1 are estimated. At t=0.01 it asks "reachable by a single nucleotide change?".

3.3 Validation methods

  • Nested CV (5 seeds × 5-fold; inner loop selects t) — nothing fit and scored on the same data.
  • Leave-one-variant-out (LOVO) de-leaking; prospective temporal forecasting (future held out).
  • Bootstrap CIs; leakage/overlap accounting; cross-signal, multi-backbone, cross-species replication.
  • Real-CDS confound control; independent adversarial verification of each headline claim.

4. Results

4.1 The CLIB offset (Phases 0–7)

After fixing a coordinate bug (a 1-based escape list silently scoring the wrong mutations), honest nested CV showed: the offset lifts a weak backbone (base ESM2 DMS 0.53 → 0.85); κ=1 is optimal (learning it gives no gain) and removes a ~30% in-sample optimism; t can be fixed at 0.01; and four complexity axes (discretization, stacking, ranking loss, richer semantics) all fail to beat the two-parameter model. CLIB-only reaches leave-one-strain-out AUROC 0.864 with a weak backbone.

4.2 Label-free coefficients & DMS-free validation (Phase B)

Regressing b0, b1 on escape-independent statistics (CLIB frozen) gives grammar ≫ semantic. Fitting on Bloom phylogenetic fitness yields (0.285, 0.942) — nearly the DMS-supervised (0.268, 0.955) — and matches supervised leakage-free DMS AUROC ≈0.90; three proxies (frequency, Bloom, temporal) converge. DMS-free validation: prospective emergence proxy_early AUROC 0.899 (> equal-weight 0.860, CI excludes 0; a within-noise tie with supervised 0.894); LOVO improvement survives 5/5 variants; phylogenetic cross-check ~0.85. On lineage tasks the frequency proxy is circular — the honest tests are DMS and temporal.

4.4 General-PLM universality (B8)

CLIB-only = 0.883 for every backbone (a universal baseline lifting each PLM from protein-only ~0.50 to ~0.88). Protein-only DMS is ~0.50 for all base sizes but 0.82 for ESM2cov — escape signal is from domain adaptation, not scale (3B no better than 150M). Label-free ≈ supervised holds for 150M and ESM2cov.

4.6 Point → Multi (B10–B11)

Hypothesis: old, diverged viruses rarely escape via a single point mutation — escape is combinatorial, so the single-mutation frame is wrong for them. Formal extension for a variant with mutation set M:

S₁ = ‖e(v) − e(xwt)‖₁   (unchanged form)
S₂ = Σ(i,a)∈M log P(a │ xwt, mask i)
CLIB(t) = Σ(i,a)∈M log P(ci → a, t)   (t free)

The single-mutation model is the case k=1, t→0; t is the point↔multi knob. Evidence: on Wu2020 combinatorial HA fitness the multi-CLIB–fitness correlation rises +0.206 (t=0.01) → +0.329 (t=10); semantic dominates (−0.459) and a signed supervised CAC recovers +0.447 (unsigned equal-weight cancels to +0.254). On H3N2 antigenic clusters (real multi-mutation escape), multi-mutation semantic predicts antigenic-cluster escape at AUROC 0.769 — far above single-mutation flu DMS escape (0.60–0.64) — with monotonic drift (mean semantic 6.4→14.4 across cluster gaps). Caveat: clusters are time-ordered, so much of the signal is temporal divergence (adjacent-cluster AUROC 0.63).

5. Discussion

Honesty as a design constraint: the offset removes a circular fit, and label-free fitting + temporal validation show generalization without touching the answer key. The prior is powerful but local: CLIB dominates for the young, low-diversity SARS-CoV-2 but is near-random for ancient Influenza/HIV; the PLM's learned representation is what transfers, and it comes from domain adaptation rather than scale. Escape has a characteristic mutational order: for old viruses escape lives at the multi-mutation level, with the CTMC time t as the natural knob.

6. Limitations

  • Label-free ≈ supervised is backbone-dependent (holds for ESM2cov; base PLMs reduce to CLIB-only).
  • The DMS test has n=19 positives → high-variance margins; weight recovery and temporal/variant results carry the claim.
  • Cross-species CLIB uses one reference strain per virus; per-lineage signatures untested.
  • The multi-mutation antigenic signal is partly temporal; a time-controlled (HI-titer) ground truth is needed.
  • Multi-mutation CLIB assumes position independence (no epistasis); its contribution decays at high mutation order.
